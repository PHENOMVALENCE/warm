# WARM — Written-Off Account Recovery Management System

Phase 1 working prototype for recovery case operations.

## Prototype scope

- Recovery dashboard and priority work queue
- Recovery case register and case detail
- Recovery activity recording
- Promise-to-pay tracking
- Payment reconciliation demo
- Maker-checker approval queue
- Operational reports and CSV demo export
- Audit trail
- Responsive desktop/mobile UI

All records in this prototype are synthetic. It does not connect to production bank systems, execute deductions, automate legal action, or make AI recovery decisions.

## Run locally

Open `index.html` in a modern browser. No build step or environment variables are required.

## Deployment

The repository is intentionally a zero-build static prototype and can be deployed directly to Vercel.
